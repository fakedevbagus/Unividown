# Phase 04: Frontend UI Foundation

## Objective
Setup layout, routing, theme system, dan base components.

## Steps
1. Configure Tailwind Theme (apps/web/tailwind.config.ts)
2. Create Theme Provider (apps/web/src/providers/theme-provider.tsx)
3. Create Layout (apps/web/src/app/layout.tsx)
4. Create Sidebar Component (apps/web/src/components/layout/sidebar.tsx)
5. Create Base UI Components (apps/web/src/components/ui/)

## Expected Output
- Layout working dengan sidebar
- Theme toggle functional
- Base components ready
- Dark mode working
